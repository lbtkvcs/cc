# SKIRIAMA ŽMOGUI — Editorial Design

**Category:** Editorial / Publication  
**Type:** Fictional concept

## Brief
Create the visual language for a small literary publication about people, memory and place.

## Direction
The cover system combines quiet photography with large serif typography. Inside, a modular grid balances long-form reading with documentary images and pull quotes.

## Deliverables
- Cover concept
- 24-page layout system
- Section openers
- Typography and grid specification
