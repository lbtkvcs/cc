# LUMA — Digital Experience

**Category:** Web / UI  
**Type:** Fictional concept

## Brief
Design a landing page for an independent creative studio that values clarity and thoughtful work.

## Direction
The interface uses a strong typographic hierarchy, generous negative space and a restrained monochrome palette. Motion is subtle and purposeful: it reveals information instead of decorating it.

## Deliverables
- Desktop landing page
- Mobile layout
- Type scale
- Component set
- Interaction notes
